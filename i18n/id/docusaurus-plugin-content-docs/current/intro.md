# Panduan Pengguna Candi TMS

# Selamat Datang di Candi TMS

**Candi TMS** adalah **Tracking & Monitoring System** yang dioperasikan oleh **PT. Candi Solusi Angkasa**. Platform ini menyediakan pusat pengelolaan delivery order, penugasan driver, dan operasional logistik last-mile.

---

## 🔐 Login Sistem

Untuk mengakses Candi TMS, buka peramban web Anda dan navigasikan ke alamat berikut:
`https://tmsmsa.com/candi/tms_login.php`

![Halaman Login TMS](/img/tms_login_screen.png)

### Langkah-Langkah Login

1. **Alamat Email:** Masukkan alamat email akun Candi Anda yang telah terdaftar pada kolom input email.
2. **Kata Sandi:** Ketik kata sandi akun Anda pada kolom password.
3. **Masuk:** Klik tombol **Login** untuk memverifikasi akun dan masuk ke dasbor Anda.

:::tip Masalah Akses
Jika Anda tidak dapat masuk ke sistem, hubungi administrator sistem Anda untuk memverifikasi kredensial akun atau mereset kata sandi Anda.
:::
