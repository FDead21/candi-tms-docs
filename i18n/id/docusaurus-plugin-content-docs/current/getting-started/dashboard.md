# Dasbor

Setelah berhasil login, Anda akan masuk ke **Dasbor** — panel kontrol utama Candi TMS. Halaman ini memberikan ringkasan aktivitas harian dan akses cepat ke seluruh modul.

![Tampilan Dasbor](/img/tms_dashboard.png)

---

## 🧭 Navigasi Antarmuka

Layar terbagi menjadi tiga area utama:

1. **Menu Sidebar Kiri** — navigasi utama Anda. Seluruh modul dikelompokkan di sini:
   - **Master Data** — Shipper, Consignee, Contract Data (Contract, Price, Price Check)
   - **AWB Data** — Upload Data, Booking Order (Entry Data, Delivery Order)
   - **Driver** — Order Driver, Booking Driver, Update Status
2. **Bilah Atas (Top Bar)** — berisi kotak pencarian, notifikasi, dan menu akun Anda (termasuk **Logout**).
3. **Area Konten Utama** — menampilkan widget dasbor dan, saat Anda membuka modul, layar kerja modul tersebut.

---

## 📊 Widget Dasbor

### Daily Shipment (Pengiriman Harian)
Ringkasan aktivitas kargo hari ini:
- **Total Shipment** — jumlah pengiriman yang tercatat hari ini.
- **Total Weight** — total berat (dalam KG) pengiriman hari ini.

### Pintasan AWB Data
Ubin peluncur cepat menuju layar operasional yang paling sering digunakan:
- **Upload** → Upload Data
- **Entry Data** → entri Booking Order
- **Update Status** → layar pembaruan status
- **Invoices** → daftar faktur

### Pintasan Master Data
Ubin peluncur cepat untuk data referensi:
- **Shipper**, **Consignee**, **Contract**, **Price**

### Status Report & Activity
Penghitung yang menampilkan jumlah **Orders** dan **Invoices** pada setiap status, beserta umpan **Status Activity** berisi aktivitas sistem terbaru.

---

## 🔓 Keluar (Logout)

Untuk mengakhiri sesi dengan aman, klik nama akun Anda di pojok kanan atas lalu pilih **Logout**. Anda akan dikembalikan ke halaman login.

:::tip
Selalu logout saat menggunakan komputer bersama untuk melindungi data pelanggan dan pengiriman.
:::
