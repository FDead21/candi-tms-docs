# Shipper (Pengirim)

Modul **Shipper** menyimpan data master setiap pengirim (consignor) yang Anda layani. Setelah shipper disimpan di sini, Anda dapat memilihnya dengan cepat saat membuat booking atau shipping instruction tanpa perlu mengetik ulang detailnya.

Buka melalui sidebar: **Master Data ➔ Shipper**.

![Daftar Shipper](/img/tms_shipper_main.png)

---

## 📋 Daftar Shipper

Layar utama menampilkan tabel berisi seluruh shipper yang dapat dicari dan memiliki halaman (pagination). Gunakan kotak **Search** untuk memfilter berdasarkan nama atau kolom mana pun, dan klik judul kolom untuk mengurutkan. Setiap baris memiliki tombol **Action** untuk **Edit** atau **Delete** shipper tersebut.

---

## ➕ Menambah Shipper Baru

1. Klik tombol **Add Shipper** di atas tabel.
2. Formulir **Add Shipper** akan terbuka. Isi kolom berikut:

   | Kolom | Keterangan |
   |---|---|
   | **ID** | Identitas unik shipper (dapat dibuat otomatis). |
   | **Name** | Nama perusahaan atau perorangan pengirim. |
   | **NPWP** | Nomor Pokok Wajib Pajak. |
   | **Phone** | Nomor telepon utama. |
   | **Email** | Alamat email kontak. |
   | **Address** | Alamat lengkap. |
   | **City** | Kota. |
   | **Postal Code** | Kode pos. |
   | **Country** | Negara. |
   | **PIC** | Penanggung jawab (narahubung). |
   | **PIC Phone** | Nomor telepon langsung PIC. |

3. Klik **Save changes** untuk menyimpan. Gunakan **Reset** untuk mengosongkan formulir atau **Cancel** untuk menutup tanpa menyimpan.

---

## ✏️ Mengubah Shipper

1. Temukan shipper di daftar (gunakan **Search** bila perlu).
2. Klik tombol **Edit** pada baris tersebut.
3. Formulir **Edit Shipper** terbuka berisi data yang sudah ada.
4. Perbarui kolom lalu klik **Save changes**.

---

## 🗑️ Menghapus Shipper

1. Klik tombol **Delete** pada baris shipper.
2. Konfirmasikan tindakan saat diminta.

:::caution
Menghapus shipper yang sudah terkait dengan booking dapat memengaruhi data tersebut. Pastikan shipper tidak lagi digunakan sebelum menghapus.
:::
