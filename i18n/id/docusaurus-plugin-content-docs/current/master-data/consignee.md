# Consignee (Penerima)

Modul **Consignee** menyimpan data master setiap penerima (pihak yang menerima barang). Menyimpan consignee di sini memungkinkan Anda memilihnya secara instan saat membuat booking dan delivery order.

Buka melalui sidebar: **Master Data ➔ Consignee**.

![Daftar Consignee](/img/tms_consignee_main.png)

---

## 📋 Daftar Consignee

Layar utama menampilkan tabel seluruh consignee yang dapat dicari dan memiliki halaman. Gunakan kotak **Search** untuk memfilter dan klik judul kolom untuk mengurutkan. Setiap baris memiliki tombol **Action** untuk **Edit** atau **Delete**.

---

## ➕ Menambah Consignee Baru

1. Klik tombol **Add Consignee** di atas tabel.
2. Isi formulir **Add Consignee**:

   | Kolom | Keterangan |
   |---|---|
   | **ID** | Identitas unik consignee (dapat dibuat otomatis). |
   | **Name** | Nama perusahaan atau perorangan penerima. |
   | **NPWP** | Nomor Pokok Wajib Pajak. |
   | **Phone** | Nomor telepon utama. |
   | **Email** | Alamat email kontak. |
   | **Address** | Alamat pengiriman lengkap. |
   | **City** | Kota. |
   | **Postal Code** | Kode pos. |
   | **Country** | Negara. |
   | **PIC** | Penanggung jawab (narahubung). |
   | **PIC Phone** | Nomor telepon langsung PIC. |

3. Klik **Save changes** untuk menyimpan.

---

## ✏️ Mengubah Consignee

1. Temukan consignee di daftar.
2. Klik **Edit** pada barisnya.
3. Perbarui formulir **Edit Consignee** yang sudah terisi lalu klik **Save changes**.

---

## 🗑️ Menghapus Consignee

1. Klik **Delete** pada baris consignee.
2. Konfirmasikan saat diminta.

:::caution
Consignee yang terkait dengan pengiriman aktif sebaiknya tidak dihapus sampai data tersebut selesai atau dialihkan.
:::
