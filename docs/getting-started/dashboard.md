# Dashboard

After a successful login, you land on the **Dashboard** — the central control panel of Candi TMS. It gives you an at-a-glance overview of daily activity and quick access to every module.

![Dashboard Overview](/img/tms_dashboard.png)

---

## 🧭 Navigating the Interface

The screen is divided into three main areas:

1. **Left Sidebar Menu** — your primary navigation. All modules are grouped here:
   - **Master Data** — Shipper, Consignee, Contract Data (Contract, Price, Price Check)
   - **AWB Data** — Upload Data, Booking Order (Entry Data, Delivery Order)
   - **Driver** — Order Driver, Booking Driver, Update Status
2. **Top Bar** — contains the search box, notifications, and your account menu (including **Logout**).
3. **Main Content Area** — displays the dashboard widgets and, when you open a module, that module's working screen.

---

## 📊 Dashboard Widgets

### Daily Shipment
A summary of the current day's cargo activity:
- **Total Shipment** — number of shipments recorded today.
- **Total Weight** — combined weight (in KG) of today's shipments.

### AWB Data Shortcuts
Quick-launch tiles that jump directly to the most-used operational screens:
- **Upload** → Upload Data
- **Entry Data** → Booking Order entry
- **Update Status** → status update screens
- **Invoices** → invoice list

### Master Data Shortcuts
Quick-launch tiles for reference data:
- **Shipper**, **Consignee**, **Contract**, **Price**

### Status Report & Activity
Counters showing the number of **Orders** and **Invoices** at each status, plus a running **Status Activity** feed of recent system events.

---

## 🔓 Logging Out

To end your session securely, click your account name in the top-right corner and select **Logout**. You will be returned to the login screen.

:::tip
Always log out when working on a shared computer to protect customer and shipment data.
:::
