# Price Check

The **Price Check** tool lets you quickly look up the applicable rate for a given contract and route without scrolling through the full price list. It's handy when quoting a customer or verifying a charge.

Open it from the sidebar: **Master Data ➔ Contract Data ➔ Price Check**.

![Price Check](/img/tms_price_check.png)

---

## 🔍 Checking a Price

1. Set the search criteria at the top of the page:

   | Field | Description |
   |---|---|
   | **Contract** | Select the contract to check against. |
   | **Contract Type** | Filter by the contract type. |
   | **Contract Product** | Filter by the product/service. |
   | **Origin** | Origin location. |
   | **Destination** | Destination location. |

2. The results table refreshes to show the matching rate(s) with these columns:
   - **No.**, **Contract**, **Type**, **Product**, **Origin**, **Destination**, **Cost**, **Price**.

3. Read off the **Cost** and **Price** for the route you searched.

:::tip
If no result appears, the route/product combination may not yet have a rate defined. Add it under [Price](./price.md).
:::
