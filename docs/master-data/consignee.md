# Consignee

The **Consignee** module stores the master records of every recipient (the party receiving the goods). Saving consignees here lets you select them instantly during booking and delivery order creation.

Open it from the sidebar: **Master Data ➔ Consignee**.

![Consignee List](/img/tms_consignee_main.png)

---

## 📋 The Consignee List

The main screen shows a searchable, paginated table of all saved consignees. Use the **Search** box to filter and click any column header to sort. Each row has **Action** buttons to **Edit** or **Delete**.

---

## ➕ Adding a New Consignee

1. Click the **Add Consignee** button above the table.
2. Fill in the **Add Consignee** form:

   | Field | Description |
   |---|---|
   | **ID** | Unique consignee identifier (may be auto-generated). |
   | **Name** | Company or person name of the recipient. |
   | **NPWP** | Tax identification number (*Nomor Pokok Wajib Pajak*). |
   | **Phone** | Main contact phone number. |
   | **Email** | Contact email address. |
   | **Address** | Full delivery street address. |
   | **City** | City. |
   | **Postal Code** | ZIP / postal code. |
   | **Country** | Country. |
   | **PIC** | Person in charge (contact person). |
   | **PIC Phone** | Direct phone number of the PIC. |

3. Click **Save changes** to store the record.

---

## ✏️ Editing a Consignee

1. Locate the consignee in the list.
2. Click **Edit** on its row.
3. Update the pre-filled **Edit Consignee** form and click **Save changes**.

---

## 🗑️ Deleting a Consignee

1. Click **Delete** on the consignee's row.
2. Confirm when prompted.

:::caution
A consignee linked to active deliveries should not be deleted until those records are completed or reassigned.
:::
